Los 4 prompts

Antes de empezar

Instagram ahora permite múltiples captions dentro del mismo carrusel. Eso significa que cada slide puede posicionar en una búsqueda distinta. Pero no se trata de llenar todo de keywords — se trata de darle a Instagram contexto real sobre lo que estás publicando.

Estos 4 prompts cubren el proceso completo: desde mapear tu audiencia hasta el caption de cada slide y la auditoría antes de publicar.

01

Mapea las intenciones de búsqueda

Antes de escribir una sola palabra, define qué busca tu audiencia en cada slide. Este prompt te da el mapa completo del carrusel.

Prompt

Actúa como experto en SEO para redes sociales.

Mi carrusel habla de: [TEMA DEL CARRUSEL]
Mi audiencia ideal: [A QUIÉN LE HABLAS]
Número de slides: [N]

Con esa información:
1. Define una intención de búsqueda diferente para cada slide.
   Cada una debe ser una frase real que alguien escribiría en Instagram o Google.
2. Ordénalas de la más general (slide 1) a la más específica (último slide).
3. Asegúrate de que ninguna intención se repita entre slides.

Entrega el resultado en tabla:
Slide | Intención de búsqueda | Keyword principal
💡

Por qué primero: Si no mapeas antes, terminas escribiendo el mismo tema con otras palabras. Cada slide necesita territorio propio para que Instagram no los compita entre sí.

02

Escribe el copy de los slides

El texto de cada slide es lo que Instagram lee para entender tu contenido. Tiene que describir lo que se ve, con la intención de búsqueda de ese slide.

Prompt

Actúa como estratega de contenido con experiencia en SEO para Instagram.

Tengo un carrusel sobre: [TEMA]
Aquí está la tabla de intenciones que generamos:
[PEGA LA TABLA DEL PROMPT 01]

Para cada slide escribe:
- Título o frase principal (máx. 8 palabras, incluye la keyword del slide)
- Subtítulo o copy de apoyo (1-2 líneas que desarrollen la idea)
- CTA del slide (solo para el último: acción específica, no "desliza para más")

Tono: directo, sin relleno, para personas reales.
No repitas keywords entre slides.

Formato de entrega:
SLIDE 1
Título: ...
Copy: ...

SLIDE 2
Título: ...
Copy: ...
[continúa hasta el último slide]
💡

La regla más importante: Describe lo que se VE en el slide, no lo que quieres que piensen. Instagram usa ese texto para entender el contenido visual.

03

Escribe el caption de cada slide

Esta es la feature nueva. Cada slide tiene su propio caption independiente. Aquí es donde le dices a Instagram de qué trata específicamente ese slide — con su propia intención de búsqueda.

Prompt

Actúa como experto en SEO para Instagram.

Tengo un carrusel sobre: [TEMA]
Aquí está la tabla de intenciones y el copy de cada slide:
[PEGA LA TABLA DEL PROMPT 01 Y EL COPY DEL PROMPT 02]

Ahora escribe el caption individual de cada slide usando la feature
de múltiples captions de Instagram.

Para cada slide:
- 1 oración que describa exactamente lo que se ve en ese slide
- Incluye la keyword asignada de forma natural, no forzada
- Máximo 125 caracteres por caption
- Cada caption debe sonar diferente al anterior
- No repitas keywords entre slides

Formato de entrega:
Caption slide 1: ...
Caption slide 2: ...
Caption slide 3: ...
[continúa hasta el último slide]
💡

Cómo activarlo: Crea el carrusel → toca el área del caption → activa "Múltiples captions". Cada slide tendrá su propio campo de texto. Este prompt te da exactamente lo que va en cada uno.

04

Audita todo antes de publicar

Una revisión de 2 minutos puede duplicar el alcance orgánico. Este prompt detecta keywords repetidas, copy vacío y CTAs genéricos.

Prompt

Actúa como auditor de SEO para Instagram.

Aquí está el contenido completo de mi carrusel sobre [TEMA]:

CAPTION DEL POST:
[PEGA EL CAPTION]

COPY DE SLIDES:
[PEGA TODOS LOS SLIDES]

Revísalo y dime:
1. ¿La keyword principal aparece en las primeras palabras del caption?
2. ¿Alguna keyword se repite entre slides? Si sí, sugiere reemplazo.
3. ¿Algún slide tiene copy que no describe lo que se ve visualmente?
4. ¿Las intenciones de búsqueda son variadas o todas apuntan al mismo tema?
5. ¿El último slide tiene un CTA específico (no genérico)?
6. ¿El caption suena natural o parece escrito para el algoritmo?

Entrega: puntuación del 1 al 10 + lista de correcciones prioritarias.
💡

Antes de publicar: Si el copy del slide repite lo que ya se lee en la imagen, está de más. El texto tiene que añadir contexto, no duplicar lo visual.

Para no arruinarlo

Reglas rápidas

✅Keyword principal en las primeras palabras del caption.
✅Cada slide tiene una intención de búsqueda distinta.
✅El copy del slide describe lo que se VE.
✅El último slide siempre tiene CTA específico.
❌No repitas la misma keyword en más de un slide.
❌No copies el texto visual del slide en su caption.
❌No termines con "desliza para más".
❌No publiques sin pasar por el Prompt 04.
